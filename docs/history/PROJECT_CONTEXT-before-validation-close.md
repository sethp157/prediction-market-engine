# Project context

## Confirmed intent

The user selected **test viability first**: investigate whether repeatable prediction-market edge exists. Learning and a useful portfolio project are secondary benefits, not substitutes for evidence of viability.

The user wants incremental research, mathematical documentation, explicit decisions before advancement, durable context, and guardrails for AI-assisted work. The evaluation engine should emerge from the questions and evidence the program actually needs.

## What a useful outcome looks like

- A supported reason to continue evaluating a narrowly defined method; or
- A supported reason to stop or revise because the apparent advantage disappears, cannot be evaluated honestly, or is impractical to exploit; or
- An explicit inconclusive result identifying the missing evidence and whether obtaining it is worthwhile.

No monthly-income target is an acceptance criterion. The project must not optimize its analysis toward a desired profit figure. “Economically meaningful” remains undefined until the required costs, effect sizes, capital assumptions, and resource constraints are specified.
